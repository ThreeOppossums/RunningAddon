# RunningAddon

This add-on helps you animate TF2 characters using the three default walk animations: `run_PRIMARY`, `run_SECONDARY`, and `run_MELEE`. It also features an easy-to-use path-creation tool for controllable movement.

*Note: This add-on is in an early stage of development. Some features may be missing or might not work as intended, but this does not affect the core functionality.*

## Version
1.0.0

## Features
- **Path Creation:** Create paths for the character by placing markers.
- **Auto-Animation:** Animate characters along these paths using original TF2 movement animations and matching speeds.

## Installation
1. Download the latest version as a ZIP file from GitHub or my website. Please note that my website might not always be online.
2. Download the latest version of the "files" folder.
3. Open Blender and go to **Edit > Preferences > Add-ons > Install...**
4. Select the downloaded ZIP file and click **Install**.
5. Unzip the separate "files" folder to a location of your choice.
6. In Blender, go to the **Scene Properties** tab, find the **RunningAddon Settings**, and click on the file path button to select the unzipped files folder.

## Installation (Tipps)
Although you can import the models directly from TF2, I highly recommend using [Hisanimations' TF2 Trifecta Addon](https://github.com/hisprofile/TF2-Trifecta).

## Location
You can find the add-on interface in the 3D Viewport sidebar (press N).
